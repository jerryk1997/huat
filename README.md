# Huat

Personal finance for Singapore — spending, budgets, goals, CPF projection and insurance
in one picture. **Huat** (發/发, Hokkien): "to prosper".

**Status:** design phase, no app code.

- **Humans:** open [`handbook/huat-handbook.html`](handbook/huat-handbook.html) — the full,
  formatted project documentation (generated).
- **AI assistants:** read [`START_HERE.md`](START_HERE.md), then [`STATUS.md`](STATUS.md).
- Prototypes: `open docs/design/prototypes/index.html`.
- Rebuild handbook: `python3 scripts/build_handbook.py`.
