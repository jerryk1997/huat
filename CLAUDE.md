# CLAUDE.md

**Read `START_HERE.md` now, then `STATUS.md`.** They explain this repository and how
to work in it.

Short version: this repo is a second brain for designing **Huat**, a Singapore
personal-finance app. There is no application code yet — it holds product
requirements, design exploration and decision history. Work happens across many
separate chat sessions with no shared memory, so the repo is the only continuity.

Non-negotiables (full detail in `START_HERE.md`):

- `docs/decisions/` entries are settled. Don't re-litigate; supersede with a new ADR.
- Mark anything Jerry hasn't confirmed as `PROPOSED`.
- `docs/reference/` numbers carry as-of dates. Check them before quoting.
- Before ending a session: update `STATUS.md`, add a journal entry, write ADRs for
  decisions, fold durable facts into the living docs, then commit and push.
