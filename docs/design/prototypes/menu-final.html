Rest

Pressing the FAB collapses its 3px offset shadow so it appears to "press into" the screen — a satisfying physical interaction that matches the brutalist stamp aesthetic. When the quick-add sheet opens, the "+" rotates 45° into an "×" (close), and the fill inverts to ink black.
Dev Note
React Native implementation: use a custom BottomTabBar from React Navigation. The center "tab" is replaced by an empty placeholder column, and the FAB is absolutely positioned over the bar with zIndex: 6. Active marker is a 38×5 absolutely-positioned View on top edge of each tab.

Safe area handling: the bar should sit above the home indicator. On iPhone Pro models with no notch but rounded bottom, add 16–20px bottom inset. The FAB's tap target should extend INTO the safe area for thumb comfort but the visual circle stays at 54px.

Hit testing edge case: the FAB overlaps slightly with the Txns and Insurance tabs. Make sure FAB owns those 27px on either side of center — easiest way is the absolute-positioned FAB has hitSlop: { top: 10, left: 10, right: 10, bottom: 0 }.
