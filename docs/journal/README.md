# Journal

One entry per working session: `YYYY-MM-DD-slug.md`. **Append-only** — add entries,
never rewrite them. Use the real date of the session.

The journal records *that* something happened and why. It is not where current facts
live — those belong in the living docs (`STATUS.md`, `docs/product/`,
`docs/architecture/`). If you only write a journal entry, the next session has to
reconstruct the present by reading history, which defeats the point.

## Template

```markdown
# YYYY-MM-DD — <topic>

## What we worked on
## Decisions made
(link to the ADR for each)
## Still open
## Next session should
```
