# 0005 — Name the product "Huat"

**Status:** Accepted
**Date:** 2026-11-18

## Context
The project was scaffolded as `expense-tracker`, which undersold a product covering
CPF projection, insurance coverage, goals and AI insight. A real name was needed
before design and any store listing.

## Decision
**Huat** (發 / 发, Hokkien — "to prosper", as in *huat ah*). Folder, repo and all
docs renamed on 2026-11-18.

## Consequences
- Warm, memorable and unmistakably Singaporean — matches an SG-only v1 audience.
- **Does not travel.** The name is near-meaningless outside Singapore and the wider
  Hokkien-speaking diaspora. Expanding markets would mean a rename or a sub-brand;
  accepted knowingly.
- Reads as playful rather than institutional. Fine for a personal-finance habit app;
  something to re-examine if the product ever targets institutional trust.
- Short and clean for a bundle ID and domain.

## Alternatives considered
- **nett** — SG term for take-home pay, directly names the core CPF calculation.
  Precise but cooler in tone.
- **steady** — Singlish for reliable/solid; warm, but a common word and hard to search.
- **keel** — stability plus SG port heritage; too abstract without a tagline.
- **kopi**, **tally** — both already crowded with existing apps.
